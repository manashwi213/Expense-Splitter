# Expense Splitter 💰

A simple Python-based Expense Splitter that helps groups manage their shared expenses and calculate how much each person should pay or receive.

## 📌 About the Project

Expense Splitter is a command-line application developed using Python.

It allows users to:

- Add people to a group
- Add expenses made by different people
- View all recorded expenses
- Calculate the total expense
- Calculate each person's equal share
- Check how much each person should pay or receive

## ✨ Features

### 1. Add Person
Users can add multiple people to the group.

### 2. Add Expense
Users can record:
- Person who paid
- Amount
- Expense description

### 3. View Expenses
Display all expenses recorded in the current session.

### 4. Calculate Split
The application calculates:
- Total group expense
- Number of people
- Equal share per person
- Individual balance
